{% if page.lang == 'en' %}Model & calculation notes{% else %}模型与计算说明{% endif %}

{% if page.lang == 'en' %}Uses the 16 nitrogen and helium compartments of Bühlmann ZHL-16C, Schreiner tissue updates and GF-controlled planned ascent.{% else %}采用 Bühlmann ZHL-16C 的 16 组氮、氦参数，使用 Schreiner 方程更新组织压力，并用 GF 约束上升。{% endif %}

  • {% if page.lang == 'en' %}Visualization follows the entered profile without adding ascent or switch dwell; GF High and Low reference ceilings are shown separately. GF99 is the maximum current-depth tissue gradient, floored at zero. SurfGF uses surface pressure instead.{% else %}可视化仅执行输入分段，不添加上升或换气停留，分别绘出 GF High 和 GF Low 参考上限。GF99 为当前深度各腔隔梯度的最大值，最低显示 0；水面 GF 则使用水面气压计算。{% endif %}
  • {% if page.lang == 'en' %}Tissues start equilibrated with local surface air. Repetitive dives, CCR, residual nitrogen and no-fly times are not supported.{% else %}初始组织在当地水面空气中达到平衡；不支持重复潜水、CCR、残余氮或飞行等待时间计算。{% endif %}
  • {% if page.lang == 'en' %}In the planner, GF Low anchors the first constrained depth, then interpolates linearly with depth to GF High at the surface.{% else %}计划页的 GF Low 锚定首次受限深度，随后按深度线性过渡到水面的 GF High。{% endif %}
  • {% if page.lang == 'en' %}Automatic stops use 3 m spacing and 1 min increments. The next depth is checked before leaving; ascent is checked at 1 s intervals. The page adds no gas-switch dwell or optional safety stop.{% else %}自动减压按 3 m 分站，停留以 1 min 递增；离站时检查下一深度上限，并按 1 s 检查移动过程。页面不添加气体切换耗时或额外安全停留。{% endif %}
  • {% if page.lang == 'en' %}Default salt-water density is 1.03 kg/L; water vapour pressure is 0.0627 bar. SCR uses equivalent gas volume at 1 bar.{% else %}海水默认密度 1.03 kg/L；水汽压为 0.0627 bar。SAC 采用 1 bar 等效气量。{% endif %}
  • {% if page.lang == 'en' %}CNS interpolates the NOAA single-exposure table; values above 1.6 ata cannot be fully estimated. OTU uses power-law accumulation. Prior oxygen exposure is not modeled.{% else %}CNS 采用 NOAA 单次暴露表的插值估算，超过 1.6 ata 时显示无法完整估算；OTU 采用标准幂律累计。二者均不模拟此前氧暴露。{% endif %}

{% if page.lang == 'en' %}This is a learning tool, not a certified decompression device. Numerical verification does not establish the safety of an actual dive.{% else %}本工具用于学习与演示，不是经过认证的减压设备。参数或数值验证通过，不代表某次真实潜水的安全保证。{% endif %}
